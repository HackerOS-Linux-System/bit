Settings

Everything here is stored only in this browser.

GitHub token

When you open a library, bit.io asks GitHub's API for its file tree (languages and the source browser) and its releases. Anonymous requests are limited to 60 per hour per IP address; with a personal access token the limit is 5,000 per hour.

The token is used only on a library's detail page and only for api.github.com. It is never sent to raw.githubusercontent.com or to bit.io. A token with no scopes (or a fine-grained, read-only, public-repositories token) is enough — create one ↗.

Offline mode

Libraries you open are saved in this browser (details, README, file tree, files you read, releases). Without a connection the site still opens and shows that saved copy, with a notice at the top.
